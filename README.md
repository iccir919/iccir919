## 🌟 Featured Projects

### ⏱️ [Screen Time Tracker](https://github.com/iccir919/screen-time-tracker)

Explore your iPhone and Mac Screen Time to understand where your time goes. Apple only keeps about four weeks of history, so this also saves your usage into your own database on your Mac, for as long as you want.

- **Features:** Reads and decodes Apple's internal Screen Time stores (knowledgeC and Biome), checks totals against Apple's own numbers, local dashboard with a one-click Refresh, editable app names and categories, daily scheduler
- **Tech:** Node.js (built-in `http` and `node:sqlite`, no dependencies), vanilla JavaScript, HTML, CSS

### 🔥 [Streak Seeker](https://github.com/iccir919/streak-seeker)

A privacy-first habit tracker that lives in your browser. Build daily streaks with no login and no data collection, since everything stays on your device.

- **Features:** Drag-and-drop habit ordering, GitHub-style heatmap, streak stats and completion rates, archiving
- **Tech:** React, Vite, Chrome Extensions (Manifest V3), localStorage, @dnd-kit
- **Live:** [Chrome Web Store](https://chromewebstore.google.com/detail/jbldckdbhaibiejndigjmgdaacainphh)

### 📅 [Time Tracker](https://github.com/iccir919/time-tracker)

See where your time actually goes. Connects to Google Calendar and charts the hours you spend on each kind of event.

- **Features:** Rolling and custom date ranges, grouping by day, week, month, weekday, or time of day, click-to-hide events, custom colors, remembered settings
- **Tech:** React, Google Calendar API (OAuth 2.0, read-only), Recharts, localStorage

### 🚲 [Bay Wheels Unlocked 2025](https://github.com/iccir919/bay-wheels-unlocked-2025)

An end-to-end data platform for San Francisco's bike-share system. A custom ETL pipeline processes millions of raw trip records into an interactive dashboard of routes, peak hours, and station trends.

- **Features:** Streaming CSV ingestion, indexed SQL analysis, Haversine distance calculations in SQL, route and station maps, KPI and trend charts
- **Tech:** Node.js, PGlite (WASM PostgreSQL), SQL, React, Vite, Tailwind CSS, react-leaflet, recharts
- **Live:** [bay-wheels-unlocked-2025.vercel.app](https://bay-wheels-unlocked-2025.vercel.app/)

### ❤️ [Pulse Watch](https://github.com/iccir919/pulseWatch) · 41⭐ · *retired*

My first real project. It let people chart and download their own Fitbit heart rate data, and reached over 100 monthly active users. It stopped working when Google shut down the Fitbit Web API in November 2026, and the repo is now a record of the project.

- **Tech:** HTML, JavaScript, Fitbit Web API (OAuth), client-side only
